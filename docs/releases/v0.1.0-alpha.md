# Atom Browser 0.1.0 Alpha - Windows x64

Includes Chromium 156.0.8078.79, Atom Browser branding, corporate new-tab page, Kurchatov emblem, bundled public CA resources and GOST/MSSPI integration.

Windows 10 22H2 x64 installation and startup were verified.
Sandbox diagnostics showed Renderer Lockdown/Untrusted and Network Service AppContainer.

Known limitations:
- Alpha / Developer Build, not a stable release.
- GOST TLS interoperability testing pending.
- CryptoPro CSP, CAdES, Rutoken and JaCarta require separate testing.
- Astra Linux 1.8 runtime compatibility not verified.
- Installer is not digitally signed.
- User selects the default browser in Windows settings.
