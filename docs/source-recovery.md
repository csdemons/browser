# Source recovery

Use the exact revisions from `UPSTREAM.lock`.

1. Obtain Chromium `156.0.8078.79` and sync DEPS.
2. Set `third_party/boringssl/src` to the pinned BoringSSL commit.
3. From Chromium source root, run `git apply --check patches/chromium/atom-browser-0.1.0-alpha.patch`, then `git apply`.
4. From `third_party/boringssl/src`, apply `patches/boringssl/atom-gost-0.1.0-alpha.patch`.
5. Copy the contents of `patches/source-files/chromium/` into Chromium source root, preserving paths.
6. Copy the contents of `patches/source-files/boringssl/` into BoringSSL source root, preserving paths.
7. Verify files against `patches/source-files-manifest.json`.
8. Obtain CryptoPro SDK headers from a separately licensed installation if required; they are not in this public repository.
9. Use `config/windows/args-AtomWin.gn`.

Generated MIDL `.tlb` files are excluded and should be regenerated by Chromium build hooks.
