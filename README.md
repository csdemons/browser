# Atom Browser

Atom Browser is a Chromium-based web browser project.

## Version

0.1.0 Alpha

## Target Platforms

- Windows x64
- Astra Linux 1.8 x86-64

## Planned Features

- Chromium Blink/V8 engine
- GOST TLS support
- CryptoPro CSP / CAdES Browser Plugin
- Rutoken and JaCarta compatibility
- Russian trusted certification authorities
- Standard Chromium extensions
- Secure browsing with sandbox isolation

## Upstream

- Chromium 156.0.8078.79
- Chromium-Gost
- MSSPI

Exact upstream revisions are recorded in UPSTREAM.lock.

Development environment preparation and security review.
